# Tipos de Commits Comunes

✨ feat (Nueva característica)

🐛 fix (Corrección de error / Bug)

📚 docs (Cambios en la documentación)

💎 style (Formato, espacios, punto y coma; sin cambios en código fuente)

📦 refactor (Refactorización del código: ni arregla bugs ni añade features)

🚀 perf (Mejoras de rendimiento)

🚨 test (Adición o corrección de pruebas)

⚙️ chore (Tareas de mantenimiento, cambios en herramientas o dependencias)

🧹 cleanup (Limpieza de código obsoleto o archivos temporales)

🔒 security (Corrección de vulnerabilidades o problemas de seguridad)
